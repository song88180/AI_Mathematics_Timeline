# AI Mathematics Timeline

## Open the page
Serve this folder with a local web server, then open index.html in a modern browser.
For example, run `python3 -m http.server` and visit `http://localhost:8000`.
Internet access is needed only to visit source links.

## Files
- index.html: page layout, styles, graph rendering, and interactions.
- achievements.json: the single source of achievement dates, descriptions, statuses, tiers, and links.
- LICENSE.txt: attribution and licensing information.

## Use
Hover over, focus, or tap a point to open its description and source. On small screens, swipe the chart horizontally.
Open circles represent notable advances; solid circles major advances; gold stars landmarks.
Only landmarks are labeled on the graph.

## Edit
Edit achievements.json to add, remove, or revise plotted achievements. The page loads and
chronologically sorts these records automatically; entries sharing a date retain their JSON order.

## Dates and counting
Snapshot: 13 September 2026. Each point is one reported achievement or batch, including
formalizations and unverified claims. Dates use the publication date of the cited manuscript
or official report. Source links appear in the tooltips.
Importance tiers are editorial judgments, not Wikipedia ratings.
